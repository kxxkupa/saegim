# Flutter Project - 새김

### **✔️ 프로젝트 소개**

'새김'은 사용자의 중요한 일정을 체계적으로 관리할 수 있는 **개인 맞춤형 일정 관리 애플리케이션**입니다.  
주요 일정, 메모, 디데이를 한곳에서 효율적으로 관리할 수 있도록 돕습니다.

### **🗓️ 개발 정보**

* **개발 기간** : 2025.08.08 ~ 2025.09.18 (약 6주)
* **팀원** : 김건우 (개인 프로젝트)
* **역할** : 프로젝트 기획, UI/UX 디자인 및 전체 기능 개발

### **💻 개발 환경 및 기술 스택**

* **언어** : Dart
* **프레임워크** : Flutter
* **데이터베이스** : Drift
* **IDE** : Visual Studio Code
* **디자인 툴** : Figma
* **API** : 공공데이터포털 **RESTful API**

### **📌 주요 기능**

#### **메인 화면**

* 현재 위치의 **날씨 정보**를 표시하여 사용자의 편의성을 높입니다.
* 오늘 날짜를 한눈에 확인할 수 있습니다.
* 탭바를 통해 오늘 저장된 일정, 메모, 디데이를 즉시 확인할 수 있어 접근성이 뛰어납니다.

#### **일정 관리**

* 직관적인 **달력 UI**를 제공하여 날짜별 일정을 쉽게 파악할 수 있습니다.
* 일정 **추가, 수정, 삭제(CRUD)** 기능이 완벽하게 구현되어 있습니다.
* 사용자 입력 시 **폼 유효성 검사**를 통해 데이터의 정확성을 확보합니다.
* **끝 시간이 시작 시간보다 빠른 경우** 저장이 불가능합니다.

#### **메모 관리**

* 메모를 'YYYY년 MM월' 형식으로 **그룹화**하여 가독성을 개선했습니다.
* 메모 **추가, 수정, 삭제(CRUD)** 기능을 지원합니다.
* 사용자 입력 시 **폼 유효성 검사**를 통해 데이터의 정확성을 확보합니다.

#### **디데이 관리**

* 디데이 **추가, 수정, 삭제(CRUD)** 기능을 제공합니다.
* 사용자 입력 시 **폼 유효성 검사**를 통해 데이터의 정확성을 확보합니다.
* **'D+'** 타입 설정 시, 시작일로부터 **경과 일수**를 자동으로 계산하여 보여줍니다.
* **'D+'** 타입 선택 시 **오늘 날짜 이후**의 날짜는 선택할 수 없도록 **유효성 검사**를 적용했습니다.
* **'D-'** 타입 설정 시, 오늘 날짜로부터 목표일까지 **남은 날짜**를 자동으로 계산하여 보여줍니다.
* **'D-'** 타입 선택 시 **시작일보다 목표일이 빠른 경우** 저장이 불가능합니다.
